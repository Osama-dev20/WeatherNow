# 🌤️ WeatherNow

A simple bilingual weather app built with **React**, **Vite**, and **Material UI**, using the **OpenWeather API**.

## ✨ Features

- 🔍 Search weather by city
- 🌡️ Current temperature and weather information
- 🌍 Arabic & English
- ↔️ RTL / LTR support
- ⏳ Loading state
- ⚠️ Error handling
- 🧹 Request cancellation with `AbortController`

## 🛠️ Technologies

- React
- Vite
- Material UI
- Axios
- OpenWeather API

## 🚀 Run Locally

```bash
git clone https://github.com/Osama-dev20/WeatherNow.git
cd WeatherNow
npm install
```

Create a `.env` file:

```env
VITE_WEATHER_API_KEY=your_api_key
```

Then run:

```bash
npm run dev
```
